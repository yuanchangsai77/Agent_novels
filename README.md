# Agent_novels

This project generates novel outlines and chapters using the Gemini API and LangChain.

## Installation

Install the dependencies with:

```bash
pip install -r requirements.txt
```

## Usage

Run `main.py` to start the Gradio interface:

```bash
python main.py
```

Make sure to configure your API key in `agents/utils/config_local.py` based on `config_example.py`.
